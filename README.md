# ❤️ I Love You Heart Animation

A simple Python project that uses the **Turtle Graphics** module to create a beautiful heart shape made entirely from the repeated text **"I Love You"**.

## 📸 Preview

The program generates a heart like this:

- ❤️ Heart created using mathematical equations
- 💖 Repeated "I Love You" text along the heart curve
- 🌙 Black background with light pink text
- 💌 Customizable center message

---

## ✨ Features

- Heart drawn using the mathematical heart equation
- Repeated **"I Love You"** text forms the heart
- Smooth Turtle Graphics animation
- Custom center message
- Easy to customize colors, font size, and text

---

## 🛠 Requirements

- Python 3.x
- Turtle (comes pre-installed with Python)
- Math module (built-in)

## 🧮 Heart Equation

The heart is generated using the famous mathematical parametric equation:

```
x = 16 sin³(t)

y = 13 cos(t)
    - 5 cos(2t)
    - 2 cos(3t)
    - cos(4t)
```
